# Crime.Net-Generated-Job-Settings
Crime.Net Generated Job Settings is a mod for PAYDAY 2.

This mod will allow you to modify how many new active jobs will spawn in, how long should they stay before they expire, and if you want a more constant timing for new active jobs to spawn in.

Reminder, that this isn't entirely final, there's still bugs and weird quirks that need patching up.
One being that, you'll need to restart your game or enter a heist and exiting out to apply said changes.

This version should work from U10-Modern PAYDAY 2. A version for Pre-U10 is in the works.

More features will be added in later, if there is request for such feature. (hopefully I can implement they properly)
